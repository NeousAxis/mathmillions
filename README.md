# ✨ MATHMILLIONS
**Lorsque les mathématiques rencontrent les cycles astrologiques.**

MATHMILLIONS est un puissant outil de prédiction pour l'EuroMillions basé sur l'analyse statistique croisée de plus de 20 ans d'archives et les cycles d'illumination lunaire.

## 🚀 Fonctionnalités
- **Analyse d'archives (2004-2026)** : Exploitation de l'intégralité du registre historique FDJ (plus de 1700 tirages).
- **Corrélation de Pearson** : Algorithme de calcul de corrélation croisée entre les numéros sortis et l'état énergétique du ciel (Poids Lunaire).
- **Génération de grilles optimisées** : Fusionne les fréquences pures et les résonances astrologiques.
- **Validation Prospective** : Système d'historique et de validation pour vérifier l'exactitude des prédictions a posteriori.
- **Interface Moderne** : Design soigné et explications dynamiques des tirages.

## 🛠️ Installation
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/NeousAxis/mathmillions.git
   cd mathmillions
   ```
2. Installez les dépendances :
   ```bash
   pip install fastapi uvicorn requests beautifulsoup4 pandas numpy pyephem
   ```
3. Lancez l'application :
   ```bash
   python main.py
   ```
4. Accédez à l'application via `http://localhost:8000`
